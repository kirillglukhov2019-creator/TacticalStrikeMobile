# Tactical Strike Mobile — максимально простой запуск

## Важно про APK
Готовый APK нельзя честно приложить без компиляции проекта Unity с Android Build Support. В среде, где подготовлен этот архив, Unity Editor и Android SDK/NDK отсутствуют, поэтому я не могу проверить или собрать настоящий APK здесь.

## Самый простой способ получить APK (один раз на компьютере)
1. Установи **Unity Hub** и **Unity 2022.3 LTS**.
2. При установке Unity отметь модули **Android Build Support**, **Android SDK & NDK Tools** и **OpenJDK**.
3. Распакуй архив и добавь папку проекта в Unity Hub через **Add project from disk**.
4. Открой проект. Дождись окончания импорта.
5. В меню Unity нажми **Tactical Strike → Create Demo Scene**, если сцена ещё не создана.
6. Нажми **Tactical Strike → Build Android APK**.
7. Готовый файл будет сохранён в папке `Build/TacticalStrike.apk`.

После сборки APK можно перенести на телефон и установить. Для установки Android может попросить разрешить установку из этого источника.

## Что в прототипе
- FPS-камера и базовое перемещение
- простая 3D-модель винтовки
- стрельба по тренировочным целям
- тестовая арена с укрытиями
- сенсорные кнопки и свайп для обзора

Это ранний прототип, а не готовая копия CS2. Карты, реалистичные модели, умный ИИ и мультиплеер требуют следующих этапов.
